# 🤖 FAQ Chatbot

A simple and interactive FAQ Chatbot developed as part of the **CodeAlpha AI Internship**. This chatbot provides instant responses to frequently asked questions through an easy-to-use chat interface.

## 📌 Features

- 💬 Interactive chat interface
- ⚡ Instant responses to FAQs
- 📱 Responsive design
- 🎨 Clean and modern user interface
- 🖥️ Easy to use

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
CodeAlpha_FAQChatbot/
│── index.html
│── style.css
│── script.js
│── README.md
```

## 🚀 How to Run

1. Download or clone the repository.
2. Open `index.html` in your web browser.
3. Type a question in the chat box.
4. Click the **Send** button.
5. The chatbot will display a response.

## 💡 Example Questions

- Hi
- Hello
- What is AI?
- What is HTML?
- What is CSS?
- What is JavaScript?
- What is CodeAlpha?
- Thank you
- Bye
